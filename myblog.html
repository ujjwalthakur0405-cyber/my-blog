Learning Programming When Everything Looks Difficult

By Thakur Ujjwal • September 2026 • 5 min read

When I started learning programming, even small programs could feel unnecessarily complicated. Sometimes the problem wasn't the code itself. I simply didn't understand why each line was there.

Over time I realised that copying a solution is very different from understanding it. Whether it is a simple C program, a Java class, or a data structure, asking "why?" has helped me much more than trying to memorise everything.

I still get stuck. The difference now is that getting stuck doesn't automatically mean I can't do it. Usually it just means there is something I haven't understood yet.

My Notes

A Little More About My Learning

College has introduced me to a lot of different subjects. Sometimes it feels like there are too many things to learn at the same time. C, Java, DBMS, mathematics, web development, data structures and AI-related subjects can easily become a long checklist.


I've started to understand that I don't need to become an expert in everything immediately. A better approach is to take one concept, understand it properly, write some code, make mistakes and then try again.


That's also why I wanted this website to be more than a collection of copied articles. These posts are supposed to represent the things I am actually learning and thinking about as a student.

MY APPROACH

Don't just learn it.
Try building it.

One thing I've noticed while studying technology is that concepts become much easier after actually using them.

A stack becomes easier when you implement one. HTML becomes easier when you create a page. Java becomes easier when you write a program. And web development becomes much more interesting when the website is actually yours.

"The goal isn't to know everything. The goal is to keep becoming better than the version of yourself who started."
